# Support

## Questions and implementation help

Use **GitHub Discussions** for:
- installation questions;
- MCP integration questions;
- adoption ideas;
- implementation patterns;
- general community conversation.

Use **Issues** for:
- reproducible bugs;
- standard feedback;
- benchmark proposals;
- documented adoption reports.

## Before opening a bug

Please include:
- operating system;
- Python version;
- package / commit version;
- provider or model, if relevant;
- minimal reproduction steps;
- logs with secrets removed.

## Commercial support

No commercial support commitment is included with the open-source project.
