# Public adoption checklist

Use this checklist before outreach.

- [ ] Repository is public.
- [ ] CI is green on `main`.
- [ ] GitHub Release `v1.0.0` is published.
- [ ] README quickstart works from a clean environment.
- [ ] Apache-2.0 code license is present.
- [ ] CC BY 4.0 written-standard license is present.
- [ ] `CITATION.cff` is present.
- [ ] `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md` are present.
- [ ] Adoption, standard-feedback, and benchmark issue forms are enabled.
- [ ] GitHub Discussions is enabled.
- [ ] Pull request template is present.
- [ ] `SECURITY.md`, `SUPPORT.md`, `FAQ.md`, and `ROADMAP.md` are published.
- [ ] Compatibility and release-process docs are published.
- [ ] `ADOPTERS.md` only lists verified adopters with consent.
- [ ] No text implies endorsement by the Holy See, an AI lab, or another institution without evidence.
- [ ] Old duplicate folder cleanup is tracked separately and is not blocking adoption.
