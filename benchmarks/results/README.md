# Community benchmark results

This directory is for reproducible benchmark reports contributed by the community.

Each result should include:
- provider;
- exact model identifier;
- evaluation date;
- standard / prompt version;
- runner version or commit;
- benchmark version;
- score table;
- raw JSON report or a link to it;
- relevant environment notes.

The deterministic `mock` provider is a pipeline baseline and must **not** be presented as a model result.

Suggested filename:

`<provider>-<model>-YYYY-MM-DD.md`

A result documents an evaluation run; it does not constitute certification or endorsement.
