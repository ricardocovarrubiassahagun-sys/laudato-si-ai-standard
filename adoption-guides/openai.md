# OpenAI Adoption Guide

Possible adoption surfaces:
- developer instructions;
- reusable prompts;
- tool calling;
- MCP-connected tools;
- evals;
- post-training / behavior design.

Recommended minimum:
1. Add the universal prompt to the system/developer layer.
2. Expose `laudato_si_check`.
3. Run the benchmark before deployment.
4. Show sources when external research materially affects the response.
